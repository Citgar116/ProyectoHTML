Etiqueta H1

¿Qué es la etiqueta H1?

La etiqueta <h1> define el título principal de una página HTML. Es la etiqueta de encabezado más importante y se utiliza para indicar el tema principal del contenido.

Ejemplo de uso

Ejemplo básico de cómo se utiliza la etiqueta <h1> en un documento HTML:

<!DOCTYPE html>
<html lang="en">
<head>
<title>Título de la página</title>
</head>
<body>
<h1>Título principal</h1>
</body>
</html>
