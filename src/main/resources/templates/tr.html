Etiqueta <tr>

¿Qué es la etiqueta <tr>?

La etiqueta <tr> se utiliza para crear una fila dentro de una tabla. Dentro de ella se colocan las celdas con la etiqueta <td>.

Ejemplo funcionando

Producto Precio
Manzana $10

Código del ejemplo

<table>

<tr>
<td>Producto</td>
<td>Precio</td>
</tr>

</table>
