Etiqueta <a>

¿Qué es la etiqueta <a>?

La etiqueta <a> se utiliza para crear enlaces (links) que permiten ir a otra página web, archivo o sección dentro de un sitio.

Los enlaces son una parte fundamental de la navegación en la web.

Ejemplo funcionando

Haz clic en el siguiente enlace:

Ir a Google

Este enlace abre la página de Google en una nueva pestaña.

Código del ejemplo

Ejemplo básico de cómo se utiliza la etiqueta <a> en un documento HTML:

<html>
<body>
<p>Ir a Google:</p>
<a href="https://www.google.com">Google</a>
</body>
</html>
