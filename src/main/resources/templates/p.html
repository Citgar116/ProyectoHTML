Etiqueta p

¿Qué es la etiqueta p?

La etiqueta <p> define un párrafo en una página HTML. Se utiliza para organizar el contenido de texto en bloques independientes.

Ejemplo de uso

Ejemplo básico de cómo se utiliza la etiqueta <p> en un documento HTML:

<!DOCTYPE html>
<html lang="en">
<head>
<title>Título de la página</title>
</head>
<body>
<h1>Título principal</h1>
<p>Este es un párrafo de ejemplo.</p>
</body>
</html>

Resultado

Este es un párrafo de ejemplo.
