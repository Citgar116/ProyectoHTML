Etiqueta Body

¿Qué es la etiqueta Body?

La etiqueta <body> contiene el contenido visible de un documento HTML, como texto, imágenes, enlaces y otros elementos.
Además, es el contenedor principal para todo lo que se muestra en la página web, y es esencial para la estructura y presentación del sitio.

Ejemplo de uso

Aquí hay un ejemplo básico de cómo se utiliza la etiqueta <body> en un documento HTML:

<!DOCTYPE html>
<html lang="en">
<head>
<title>Título de la página</title>
</head>
<body>
Contenido de la página
</body>
</html>
