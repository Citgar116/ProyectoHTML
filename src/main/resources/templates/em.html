Etiqueta em

¿Qué es la etiqueta em?

La etiqueta <em> define un texto en cursiva en una página HTML. Se utiliza para dar énfasis a una parte específica del texto.

Ejemplo de uso

Ejemplo básico de cómo se utiliza la etiqueta <em> en un documento HTML:

<!DOCTYPE html>
<html lang="en">
<head>
<title>Título de la página</title>
</head>
<body>
<h1>Título principal</h1>
<p>Este es un párrafo de ejemplo con <em>texto en cursiva</em>.</p>
</body>
</html>

Resultado

Este es un párrafo de ejemplo con texto en cursiva.
