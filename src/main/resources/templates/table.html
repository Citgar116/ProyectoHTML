Etiqueta <table>

¿Qué es la etiqueta <table>?

La etiqueta <table> se utiliza para crear tablas en HTML. Dentro de ella se organizan filas y columnas para mostrar información.

Ejemplo funcionando

Nombre Edad
Ana 20
Luis 22

Código del ejemplo

<table border="1">

<tr>
<th>Nombre</th>
<th>Edad</th>
</tr>

<tr>
<td>Ana</td>
<td>20</td>
</tr>

</table>
