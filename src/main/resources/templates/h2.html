Etiqueta H2

¿Qué es la etiqueta H2?

La etiqueta <h2> define un subtítulo en una página HTML. Se utiliza para organizar el contenido en niveles de encabezado, siendo <h1> el más importante y <h2> el siguiente en importancia.

Ejemplo de uso

Ejemplo básico de cómo se utiliza la etiqueta <h2> en un documento HTML:

<!DOCTYPE html>
<html lang="en">
<head>
<title>Título de la página</title>
</head>
<body>
<h1>Título principal</h1>
<h2>Subtítulo</h2>
</body>
</html>
