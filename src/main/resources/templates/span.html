Etiqueta span

¿Qué es la etiqueta span?

La etiqueta <span> es un contenedor en línea que se utiliza para aplicar estilo o manipular elementos dentro de un documento HTML.

Ejemplo de uso

Ejemplo básico de cómo se utiliza la etiqueta <span> en un documento HTML:

<!DOCTYPE html>
<html lang="en">
<head>
<title>Título de la página</title>
</head>
<body>
<h1>Título principal</h1>
<span>Texto en línea</span>
</body>
</html>
