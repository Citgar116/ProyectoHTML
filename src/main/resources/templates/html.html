Etiqueta HTML

¿Qué es la etiqueta HTML?

La etiqueta <html> es la raíz de un documento HTML. Es el contenedor principal que envuelve todo el contenido de la página web.

Dentro de esta etiqueta se encuentran otras etiquetas que definen la estructura y el contenido del documento, como <head> y <body>.

Ejemplo de uso

Así se ve la etiqueta <html> en un documento HTML:

<!DOCTYPE html>
<html lang="en">
<head>
<meta charset="UTF-8">
<title>Título de la página</title>
</head>
<body>
Contenido de la página
</body>
</html>
