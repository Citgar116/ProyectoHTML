Etiqueta a

¿Qué es la etiqueta a?

La etiqueta <a> define un enlace en una página HTML. Se utiliza para crear enlaces a otras páginas web o recursos.

Ejemplo de uso

Ejemplo básico de cómo se utiliza la etiqueta <a> en un documento HTML:

<!DOCTYPE html>
<html lang="en">
<head>
<title>Título de la página</title>
</head>
<body>
<h1>Título principal</h1>
<a href="https://www.ejemplo.com">Visita nuestro sitio web</a>
</body>
</html>

Resultado

Visita nuestro sitio web.
