Etiqueta strong

¿Qué es la etiqueta strong?

La etiqueta <strong> define un texto en negrita en una página HTML. Se utiliza para dar énfasis a una parte específica del texto.

Ejemplo de uso

Ejemplo básico de cómo se utiliza la etiqueta <strong> en un documento HTML:

<!DOCTYPE html>
<html lang="en">
<head>
<title>Título de la página</title>
</head>
<body>
<h1>Título principal</h1>
<p>Este es un párrafo de ejemplo con <strong>texto en negrita</strong>.</p>
</body>
</html>
